# Полноэкранная читалка документа — пакет для внедрения

Открывается по клику на документ в Базе знаний. Два столбца: слева — статус,
метрики векторизации и оглавление; справа — обзор документа или выбранная глава
с переключателем «Краткое / Весь текст» и таблицами.

---

## 1. Модель данных (на документ)

```ts
type Document = {
  title: string; type: string; typeAbbr: string;
  size: string; pages: number;
  chunkSize: number; overlap: number; chunks: number;   // размер чанка/перекрытие в токенах, число чанков
  model: string; dim: number; metric: string;            // модель эмбеддингов, размерность, метрика
  owner: string; updated: string; status: 'indexed'|'processing';
  summary: string;                                        // краткое по всему документу
  sections: Section[];
};

type Section = {
  title: string;
  chunks: number;      // = число точек в БД для этой главы
  summary: string;     // краткое по главе
  text: string;        // полный текст главы
  tables?: { name: string; cols: string[]; rows: string[][] }[];
};
```

---

## 2. Состояние экрана

```js
selectedDocId: string|null   // какой документ открыт (null = читалка закрыта)
chapterIdx: number|null      // null = показываем «Обзор документа», иначе индекс главы
contentMode: 'summary'|'full'  // для главы: краткое или весь текст
```

```js
function openDoc(id)      { selectedDocId = id; chapterIdx = null; contentMode = 'summary'; }
function closeDoc()       { selectedDocId = null; }
function openChapter(i)   { chapterIdx = i; contentMode = 'summary'; }
function backToOverview() { chapterIdx = null; contentMode = 'summary'; }
function setMode(m)       { contentMode = m; }
```

```html
      </nav>
    </aside>

    <main class="reader-content">
      <div class="content-head">

        <span class="chunk-badge" if="chapter">▦ {{ chapter.chunks }} чанк. · ◆ {{ chapter.chunks }} точ.</span>

      <div if="chapter && mode==='full'">

        <div class="table-card" for="tb in chapter.tables">
          <div class="table-head">▦ {{ tb.name }}</div>
          <table><thead><tr><th for="c in tb.cols">{{ c }}</th></tr></thead>
            <tbody><tr for="r in tb.rows"><td for="cell in r">{{ cell }}</td></tr></tbody>
          </table>
        </div>
      </div>
    </main>
  </div>
</div>
```

Использует те же CSS-переменные (`--bg`, `--surface`, `--accent`, `--muted`…), что и остальной прототип — см. `НАВИГАЦИЯ — внедрение.md` за полным списком токенов обеих тем.

**Важно:** во всех местах с текстом в одну строку (статус-чип, вкладки режима) обязательно `white-space: nowrap` — без него надписи переносятся на две строки и ломают вёрстку.

## 5. Чеклист внедрения

- [ ] Модель документа расширена полями `sections[].text` и `sections[].tables?`.
- [ ] Клик по карточке документа открывает `.reader` на весь экран (не боковую панель).
- [ ] Левая колонка: статус/размер, блок векторизации, оглавление с подсветкой активного пункта.
- [ ] Правая колонка: обзор документа по умолчанию; для главы — вкладки Краткое/Весь текст.
- [ ] В режиме «Весь текст» под текстом рендерятся таблицы главы (если есть).
- [ ] `white-space: nowrap` на статус-чипе и вкладках режима.
- [ ] Тема/переменные согласованы с остальным приложением.
