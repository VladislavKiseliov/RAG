# Единая левая навигация — пакет для внедрения

Связывает три экрана прототипа в одно приложение: **Чаты (Мессенджер) ↔ База знаний ↔ Проекты**.
Передаётся разработчику/агенту как есть. Ниже — дизайн-токены, готовый код панели и пошаговая инструкция.

---

## 1. Что внедряем

Слева на каждом экране стоит вертикальный «рейл» шириной **62px**: логотип, три раздела и переключатель темы внизу.
На текущем экране его иконка подсвечена акцентом, остальные — ссылки на соседние экраны.

| Иконка | Раздел        | Файл               |
|--------|---------------|--------------------|
| `✦`    | Чаты          | `Мессенджер.dc.html` |
| `▤`    | База знаний   | `База знаний.dc.html` |
| `◫`    | Проекты       | `Проекты.dc.html`    |

Принцип: **активный пункт** = `<div>` с фоном-акцентом (без ссылки); **неактивные** = `<a href>` на соседний экран.

---

## 2. Дизайн-токены (общие для всех экранов)

Цвета задаются как CSS-переменные на корневом контейнере `.app` (через строку `rootStyle`, собираемую в `renderVals()`).
Не хардкодить hex в разметке — только переменные, иначе сломается переключение темы.

### Тёмная тема (по умолчанию)
```
--bg:                #0a0806   фон приложения
--rail / --sidebar:  #0e0b08   фон панели и сайдбаров
--surface:           #15100a   плашки, инпуты
--card:              #110d08   карточки
--border:            rgba(255,255,255,.06)
--text:              #cabfae   основной текст
--strong:            #f3ead9   заголовки
--muted:             #7c7264   подписи, неактивные иконки
--accent:            #d9a441   акцент (золото)
--accent-ink:        #1a150f   текст на акценте
--accent-soft:       #241a10   фон активного пункта
--accent-soft-border:rgba(217,164,65,.3)
--hover:             rgba(255,255,255,.045)
--ok:                #86b98c   статус «готово / в индексе»
```

### Светлая тема
```
--bg:#fbfcfc  --rail/--sidebar:#f6f8f8  --surface:#eef1f1  --card:#ffffff
--border:#e8eaec  --text:#374151  --strong:#0e1213  --muted:#8b9197
--accent:#0891b2  --accent-ink:#ffffff  --accent-soft:#e6f4f7
--accent-soft-border:#c5e6ee  --hover:rgba(0,0,0,.035)  --ok:#3f9d54
```

**Шрифты:** `IBM Plex Sans` (интерфейс), `IBM Plex Mono` (числа/метрики, класс `.mono`).

## 3. Код панели (HTML)

Вставляется **первым дочерним элементом** внутри `.app`. Ниже — версия для экрана «Чаты»
(активен `✦`). На других экранах активным делается соответствующий пункт — см. §5.

```html
<nav style="width:62px; flex-shrink:0; background:var(--sidebar,#0e0b08);
            border-right:1px solid var(--border,rgba(255,255,255,.06));
            display:flex; flex-direction:column; align-items:center; padding:16px 0; gap:6px;">

  <!-- Логотип -->
  <div style="width:32px; height:32px; border-radius:9px; background:var(--accent,#d9a441);
              display:flex; align-items:center; justify-content:center;
              color:var(--accent-ink,#1a150f); font-weight:700; font-size:16px; margin-bottom:10px;">И</div>

  <!-- АКТИВНЫЙ пункт (Чаты): div, без href -->
  <div title="Чаты"
       style="width:40px; height:40px; border-radius:11px; display:flex;
              align-items:center; justify-content:center; font-size:17px;
              background:var(--accent-soft,#241a10);
              border:1px solid var(--accent-soft-border,rgba(217,164,65,.28));
              color:var(--accent,#d9a441);">✦</div>

  <!-- НЕактивные пункты: ссылки на соседние экраны -->
  <a href="База знаний.dc.html" title="База знаний"
     style="width:40px; height:40px; border-radius:11px; display:flex;
            align-items:center; justify-content:center; font-size:17px;
            color:var(--muted,#7c7264); text-decoration:none;"
     style-hover="background:var(--hover,rgba(255,255,255,.045)); color:var(--text,#efe8dd);">▤</a>

  <a href="Проекты.dc.html" title="Проекты"
     style="width:40px; height:40px; border-radius:11px; display:flex;
            align-items:center; justify-content:center; font-size:16px;
            color:var(--muted,#7c7264); text-decoration:none;"
     style-hover="background:var(--hover,rgba(255,255,255,.045)); color:var(--text,#efe8dd);">◫</a>

  <!-- Переключатель темы (всегда внизу) -->
  <div onClick="{{ toggleTheme }}" title="Тема"
       style="margin-top:auto; width:40px; height:40px; border-radius:11px; display:flex;
              align-items:center; justify-content:center; font-size:16px;
              color:var(--muted,#7c7264); cursor:pointer;"
       style-hover="background:var(--hover,rgba(255,255,255,.045)); color:var(--text,#efe8dd);">{{ themeIcon }}</div>
</nav>
```

> Примечание по синтаксису: `{{ toggleTheme }}`, `{{ themeIcon }}` и `style-hover` — это разметка прототипа
> (Design Component). При переносе в обычный React/HTML-проект замените:
> - `{{ toggleTheme }}` → реальный обработчик `onClick`;
> - `{{ themeIcon }}` → значение `☾`/`☀` из состояния;
> - `style-hover="..."` → CSS-класс с `:hover` (см. §6).

## 4. Логика темы (JS)

Тема одна на всё приложение, хранится в `localStorage` под ключом **`msgr-theme`** (`'dark'` | `'light'`).
Переключение на любом экране подхватывается на остальных при следующей загрузке.

```js
// чтение при старте
let theme = 'dark';
try { theme = localStorage.getItem('msgr-theme') || 'dark'; } catch (e) {}

// запись + переключение
function setTheme(t) {
  try { localStorage.setItem('msgr-theme', t); } catch (e) {}
  // ...обновить состояние и перерисовать
}

// то, что панель ждёт от экрана:
const isDark   = theme === 'dark';
const themeIcon  = isDark ? '☾' : '☀';
const toggleTheme = () => setTheme(isDark ? 'light' : 'dark');
```

Строку CSS-переменных собрать из выбранной палитры и навесить на `.app`:
```js
const t = THEMES[theme];               // объект из §2
const rootStyle =
  `--bg:${t.bg};--rail:${t.rail};--sidebar:${t.sidebar};--surface:${t.surface};` +
  `--card:${t.card};--border:${t.border};--text:${t.text};--strong:${t.strong};` +
  `--muted:${t.muted};--accent:${t.accent};--accent-ink:${t.accentInk};` +
  `--accent-soft:${t.accentSoft};--accent-soft-border:${t.accentSoftBorder};` +
  `--hover:${t.hover};--ok:${t.ok};`;
// <div class="app" style={rootStyle}> ...
```

## 5. Как сделать активным нужный пункт

На каждом экране **ровно один** пункт — активный. Разница только в этом блоке:

- **Активный** (текущий экран): тег `<div>`, без `href`, стили
  `background:var(--accent-soft); border:1px solid var(--accent-soft-border); color:var(--accent);`
- **Неактивный**: тег `<a href="…">`, цвет `var(--muted)`, и `style-hover`/`:hover` как у остальных.

То есть для экрана «Проекты»: `◫` становится `<div>`, а `✦` и `▤` — ссылками. И так далее.

## 6. Перенос в обычный проект (без синтаксиса прототипа)

Если внедряете в React/Vue/чистый HTML, а не в Design Component:

1. `style-hover="..."` → вынести в CSS-класс:
   ```css
   .rail-item { color: var(--muted); transition: background .12s, color .12s; }
   .rail-item:hover { background: var(--hover); color: var(--text); }
   .rail-item--active { background: var(--accent-soft);
     border: 1px solid var(--accent-soft-border); color: var(--accent); }
   ```
2. `{{ themeIcon }}` / `{{ toggleTheme }}` → подставить значение и обработчик из состояния.
3. `href="…dc.html"` → заменить на реальные маршруты роутера
   (например `/chats`, `/knowledge`, `/projects`).

## 7. Чеклист внедрения

- [ ] CSS-переменные обеих тем заведены и применяются к корню `.app`.
- [ ] Подключены шрифты IBM Plex Sans / IBM Plex Mono.
- [ ] Панель `<nav>` стоит первым элементом в `.app` на всех трёх экранах.
- [ ] На каждом экране активен свой пункт (см. §5).
- [ ] Тема читается/пишется в `localStorage('msgr-theme')` и общая для всех экранов.
- [ ] Ссылки ведут на реальные маршруты проекта.
- [ ] Проверено в тёмной и светлой теме.

---

## 8. Следующий шаг (опционально)

Связать конкретный проект с его чатом: кнопка «Чат проекта» в детальной карточке открывает
нужную ветку мессенджера через параметр URL (например `Мессенджер.dc.html?thread=<id>`),
а мессенджер читает этот параметр и сразу открывает ветку.
