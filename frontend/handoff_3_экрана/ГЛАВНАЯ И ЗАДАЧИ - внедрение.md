# Главная и Задачи на день — пакет для внедрения

Два новых экрана: **Главная** (стартовая страница) и **Задачи на день** (недельный планировщик
с ИИ-постановкой задач). Дополняют существующие 5 экранов (Мессенджер, База знаний, Проекты,
Заметки, Админ-панель).

---

## 1. Главная (Главная.dc.html)

Стартовый экран, первый пункт в левой панели (⌂). Без прокрутки страницы — всё в высоту окна.

### Блоки
- **Шапка**: приветствие по времени суток + глобальный поиск (по чатам/докам/заметкам) +
  быстрый доступ (4 мини-карточки со статистикой разделов).
- **Уведомления** (левая колонка, смещена к низу — сверху пустой отступ ~38% высоты):
  упоминания в чатах, новые файлы, ответы, статус индексации — каждая ссылка на источник.
- **Напоминания** (правая колонка, верх): ближайшие из Заметок, urgent выделен акцентом.
- **Мои задачи** (правая колонка, низ, начинается вровень с «Уведомлениями»): чеклист-виджет,
  задачи из проектов, клик — toggle done.

### Данные с бэкенда
```ts
type Notification = { icon:string; who:string; text:string; when:string; kind:'mention'|'file'|'review'|'system'; href:string };
type Reminder = { title:string; dueLabel:string; dueIso:string; urgent:boolean };  // urgent = due today/overdue
type MyTask = { title:string; project:string; done:boolean; id:string };
type SearchResult = { title:string; subtitle:string; kind:'chat'|'doc'|'note'|'project'; href:string };
```
Поиск — либо полнотекстовый по векторной БД (та же, что для RAG), либо отдельный быстрый индекс
title+subtitle по трём источникам.

### Пропорции колонок (без скролла всей страницы)
Левая колонка — spacer `flex:1 1 38%` + карточка `flex:1 1 62%`. Правая — карточка «Напоминания»
внутри своего spacer-блока `flex:1 1 38%`, затем карточка «Мои задачи» `flex:1 1 62%`. Так верх
«Мои задачи» совпадает по высоте с «Уведомления». При портировании на реальную вёрстку это можно
заменить на `justify-content` / grid areas — суть просто в выравнивании двух карточек по одной линии.

## 2. Задачи на день (Задачи на день.dc.html)

Пункт ☑ в левой панели. Недельный вид, 7 колонок (Пн–Вс), сегодня подсвечен акцентом,
навигация «‹ Эта неделя ›».

### Модель задачи
```ts
type Task = {
  id: string;
  day: string;                 // ISO "YYYY-MM-DD", локальная дата
  title: string;
  priority: 'high'|'med'|'low';
  manual: boolean;              // true = ручная/ИИ задача (может переноситься, удаляться), false = авто из проекта/заметки
  done: boolean;
  source: { type:'project'|'note'; icon:string; label:string; href:string } | null;
};
```

### Источники задач (как договорились)
1. **Авто из проектов** — задачи с дедлайном = этот день (`source.type='project'`, ссылка на проект).
2. **Напоминания из заметок** на этот день (`source.type='note'`).
3. **Ручной ввод** — поле «+ задача» внизу каждой колонки (Enter).
4. **ИИ-постановка** (новое) — строка сверху экрана: «Напишите ИИ, что нужно сделать»
   → парсинг свободного текста → создание задачи с датой и приоритетом.

### ИИ-постановка задачи — как реализовать по-настоящему
В прототипе `createAiTask()` — простой мок: regex ищет «завтра»/«послезавтра» для даты и
«срочно/важно/потом» для приоритета. На проде — реальный вызов LLM с промптом вида:
> Извлеки из текста пользователя задачу: {title, due_date (ISO, относительно сегодня {today}),
> priority: high|med|low}. Если дата не указана — today.

Дальше просто `POST /tasks` с результатом. Тот же паттерн подходит для **чата** — если хотите
ставить задачи прямо из переписки в Мессенджере: команда/упоминание бота в чате → тот же
эндпоинт разбора текста → задача появляется в «Задачи на день» и на «Главной» в списке «Мои задачи».

### Перенос несделанного
Невыполненные `manual:true` задачи со вчерашнего дня показываются повторно на сегодня с меткой
«перенесено» (вычисляется на фронте по `byDay` в `renderVals` — на проде проще делать явным
полем/джобой на бэкенде: полночная джоба перевешивает `day` несделанных задач на следующий день
и проставляет `carried:true`).

### Вёрстка недели
7 колонок — гибкий ряд (`flex:1 1 210px; min-width:210px`) с горизонтальным скроллом, а не жёсткий
`grid` — так длинные заголовки задач не обрезаются криво при узких колонках.

## 3. Общие требования (как и на других экранах)

- Тот же набор CSS-переменных обеих тем (см. `НАВИГАЦИЯ — внедрение.md`).
- Левая панель: единый `<nav>` с иконками ⌂ ✦ ▤ ◫ ✎ ☑ ⚙ + переключатель темы, активный пункт
  подсвечен `--accent-soft`/`--accent`. Добавьте оба новых пункта (⌂, ☑) на все остальные экраны.
- `white-space:nowrap` на однострочных лейблах рядом с иконками/точками статуса — стандартное
  правило проекта, соблюдено во всех новых блоках.
- Дата в задачах — считать локальными `getFullYear/getMonth/getDate`, не через
  `toISOString()` (даёт сдвиг на часовой пояс UTC).
