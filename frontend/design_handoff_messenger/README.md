# Handoff: Инженерный мессенджер — редизайн (тёмная + светлая темы)

## Overview
Десктопный мессенджер для инженеров: общение между собой, поиск по документации
через AI-ассистента и (в дальнейшем) ведение проектов. Этот пакет описывает редизайн
интерфейса: новая структура и формулировки сайдбара, выпадающее меню профиля по клику
на аватар, и две темы — **тёмная** (тёплое золото) и **светлая** (сланец/циан).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы,
показывающие желаемый вид и поведение, а НЕ продакшн-код для копирования напрямую.
Задача — **воссоздать эти дизайны в вашем кодовом окружении** (React / Vue / и т.п.),
используя его сложившиеся паттерны, компоненты и библиотеки. Если окружения ещё нет —
выбрать подходящий фреймворк и реализовать дизайн в нём.

- `Мессенджер.dc.html` — **главный рабочий прототип** (то, что нужно реализовать):
  обе темы, переключатель, кликабельный сайдбар, рабочий ввод сообщений.
- `Мессенджер - варианты (9 цветовых гамм).dc.html` — палитра из 9 цветовых направлений,
  из которых выбраны две. Это **только для справки** по цветам, реализовывать не нужно.
- `support.js` — рантайм прототипа. В продакшене НЕ используется.

> Прототипы написаны как «Design Components» (формат `.dc.html`). Логика вынесена в
> класс внизу файла, разметка — вверху. Читать удобно как обычный HTML + JS.

## Fidelity
**High-fidelity (hifi).** Цвета, типографика, отступы и взаимодействия финальные —
воссоздавать пиксель-в-пиксель средствами вашего дизайн-системы/компонентов.

## Interactions & Behavior
- **Выбор чата в сайдбаре** → меняется активный элемент (подсветка), заголовок/подзаголовок
  хедера и лента сообщений. Открытое меню профиля при этом закрывается.
- **Клик по строке пользователя** → открывает/закрывает меню профиля (каретка поворачивается).
- **Переключатель темы** в меню → мгновенно меняет все токены; выбор сохраняется в
  `localStorage` (ключ `msgr-theme`, значения `dark` | `light`).
- **Отправка сообщения**: Enter (без Shift) или клик по «➤» → добавляет пузырь пользователя
  и очищает поле. В чатах группы **AI-ассистент** через ~650 мс приходит ответ ассистента
  (в реальном продукте — запрос к бэкенду/AI). В DM-чатах автоответа нет.
- Hover-состояния — на всех кликабельных элементах (см. выше).

## State Management
- `theme`: `'dark' | 'light'` — инициализируется из `localStorage('msgr-theme')`, по умолчанию `dark`.
- `activeId`: id выбранного чата (по умолчанию `'api'`).
- `profileOpen`: boolean — открыто ли меню профиля.
- `input`: текущий текст в поле ввода.
- `threads`: словарь `id → массив сообщений` (`{ role: 'user'|'assistant', text }`).
- Триггеры: см. «Interactions». Отправка в AI-чат планирует отложенный ответ (заменить на
  реальный data-fetch).
