## Дальнейшие планы

### Корпоративный мессенджер
Вырасти из AI-ассистента в полноценный внутренний мессенджер с AI как встроенным участником общения.
- Личные и групповые чаты между сотрудниками
- История, уведомления, статусы
- AI-участник в любом чате по вызову

### Управление проектами
Совместная работа над проектами внутри платформы.
- Группа проекта — участники, роли, общий чат
- Хранилище файлов проекта (MinIO) с версионированием
- AI-ассистент с контекстом конкретного проекта

### AI-аудит документов
Автоматическая проверка технической документации на соответствие нормативам.
- Загрузка опросного листа / технического задания
- Проверка на соответствие ГОСТам и внутренним регламентам из базы знаний
- Отчёт с расхождениями и рекомендациями

### Расширение AI-ассистента
Текущий ассистент (RAG + LLM pipeline) как основа для расширения возможностей.
- Инструменты (tools): поиск по документам, создание задач, отправка сообщений
- Агентный режим — многошаговое выполнение задач
- Персональный контекст пользователя (роль, проекты, история)
- Интеграция с внешними системами (1С, ERP, почта)
