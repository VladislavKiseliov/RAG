ИНСТРУКЦИЯ ПО ЗАПУСКУ RAG CHAT APPLICATION

1. Установка зависимостей:
   Убедитесь, что у вас установлен Python 3.12 или выше.
   
   Если вы используете pip:
   pip install -r requirements.txt
   
   Если вы используете Poetry:
   poetry install

2. Настройка переменных окружения:
   Файл .env уже создан с необходимыми переменными.
   При необходимости измените значения в файле .env:
   - SECRET_KEY: Секретный ключ для JWT (сгенерируйте случайную строку)
   - ALGORITHM: Алгоритм шифрования JWT (по умолчанию HS256)
   - ACCESS_TOKEN_EXPIRE_MINUTES: Время жизни токена в минутах
   - SQLITE: Строка подключения к базе данных SQLite

3. Запуск бэкенда:
   python main.py
   
   Бэкенд будет доступен по адресу: http://127.0.0.1:8000

4. Запуск фронтенда:
   Перейдите в директорию frontend:
   cd frontend
   
   Установите зависимости Node.js:
   npm install
   
   Запустите фронтенд:
   npm run dev
   
   Фронтенд будет доступен по адресу: http://localhost:5173

5. Использование приложения:
   - Откройте фронтенд в браузере
   - Войдите в систему (при первом входе будет создан новый пользователь)
   - Создайте новый чат с помощью кнопки "+ Новый чат"
   - Отправляйте сообщения в чат

6. Эндпоинты API:
   - POST /auth/login - Аутентификация пользователя
   - POST /api/conversations - Создание нового чата
   - GET /api/conversations - Получение списка чатов
   - GET /api/conversations/{conversation_id} - Получение истории сообщений чата
   - POST /api/conversations/{conversation_id}/messages - Отправка сообщения
   - PATCH /api/chats/{chat_id}/rename - Переименование чата
   - DELETE /api/chats/{chat_id} - Удаление чата
