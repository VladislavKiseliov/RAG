СЕРВИС ЗАГРУЗКИ ДОКУМЕНТОВ — DOCKER И ЗАПУСК

ФАЙЛЫ
1) docker-compose.yml
   - Полный набор: redis + ingestion-api (FastAPI) + celery-worker + flower.
   - Используйте, когда нужен API и воркер вместе.

2) docker-compose.override.yml (dev режим)
   - Монтирует локальный ./app в контейнеры и включает --reload для API.
   - Позволяет менять код без пересборки образа.

3) docker-compose.celery.yml
   - Минимальный набор: redis + celery-worker + flower (без API).
   - Используйте, когда API запускается отдельно или не нужен.

4) Dockerfile
   - Собирает образ приложения для ingestion-api и celery-worker.

КОМАНДЫ
A) Полный сервис (API + воркер + redis + flower)
   cd "D:\Laboratoria\Rag OVER\RagProgramm\Document_Ingestion_Service"
   docker compose up -d

B) Полный сервис с пересборкой
   docker compose up -d --build

C) Только celery-стек (redis + воркер + flower)
   docker compose -f docker-compose.celery.yml up -d

D) Остановить сервисы
   docker compose down
   docker compose -f docker-compose.celery.yml down

ЛОГИ
   docker logs -f ingestion_api
   docker logs -f ingestion_worker
   docker logs -f ingestion_flower

WEB API (ЗАПУСК ОТДЕЛЬНО)
1) Через Docker (только API)
   docker compose up -d ingestion-api

2) Локально (без Docker)
   - Активируйте venv, затем:
     uvicorn app.main:app --host 0.0.0.0 --port 8001

ПРИМЕЧАНИЯ
- Qdrant внешний; API/воркер используют QDRANT_URL (в compose: http://host.docker.internal:6333).
- Папка с документами монтируется как /data/docs внутри контейнеров.
  В запросах API используйте /data/docs, а не Windows-пути.

ЗАПУСК БЕЗ DOCKER (ЛОКАЛЬНО)
1) Redis
   - Должен быть установлен и запущен на localhost:6379.

2) Активировать venv
   cd "D:\Laboratoria\Rag OVER\RagProgramm\Document_Ingestion_Service"
   .\.venv\Scripts\Activate.ps1

3) Запуск Celery worker
   celery -A app.tasks.celery_app worker --loglevel=info --pool=threads --concurrency=4

4) Запуск Flower (опционально)
   celery --broker=redis://localhost:6379/0 flower --port=5555

5) Запуск API
   uvicorn app.main:app --host 0.0.0.0 --port 8001

ПРИМЕЧАНИЯ
- Qdrant должен быть запущен отдельно на localhost:6333.
- Для запросов к API используйте реальные Windows-пути (например: D:\...\docs).
